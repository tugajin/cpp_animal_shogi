## 結果の読み方と次の判断

### phase0_analysis.py
- **P1 圧縮の分解**: 「差（モデル − 教師）」がカテゴリを通じてほぼ 0 なら、圧縮は混合教師の算術 → 対策は教師設計（段階A の A2/A6/A3）。モデルが教師より有意に 0 側（先手勝ちで負の差、先手負けで正の差）なら学習側の shrinkage が残っており、損失・重み付け側の優先度が上がる
- **P2 教師ノイズ地図**: s の標準偏差が大きいカテゴリが audit の漏れセル（先手負け・引き分け）と重なるか。重なれば A1（平均化）/A5（重み付け）の効きどころ
- **P4 引き分け汚染**: 引き分け対局由来レコードの割合と、「決着した対局内で draw 局面に ±1 が付いた件数」が A4 の期待効果量になる

### phase0_fragility.py
- 失敗（A の不到達、C の低下）が「維持手数=1」の層に集中していれば律速は壊れやすい局面 → 段階B の B4（開始アーカイブ）や重み付けの根拠
- 層別で平坦なら、特定の局面型ではなく全体の値の質の問題

### phase1_twins.py
- **回転ツイン**: |Δv| がほぼ 0 でなければ特徴量か変換のバグ。対称拡張の前にここを直す
- **鏡像ツイン**: 不一致が兄弟ペアの |Δv| 平均と同程度以上なら鏡像拡張 arm を解禁（符号付きバイアス監視付き）。小さければ棚上げ継続
