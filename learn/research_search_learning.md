# 文献調査: 価値のみネット + UBFM/Descent 自己対局学習に関連する論文

調査日: 2026-11-20
対象プログラム: どうぶつしょうぎ（4x3・完全解析済み）の自己対局学習。価値のみの NN、UBFM/Descent 系の最良優先ミニマックス探索、教師は探索スコア `s` と対局結果 `r` の混合（LAMBDA=0.5、train_network.py:73）。
目的: 「1世代の対局数を増やす vs 自己対局時の PO 数（po_num、現行 100）を増やす」の判断材料として、探索予算と教師の質に関する先行研究の知見を集める。

凡例: 各論文について「検証済みの事実」と「本プロジェクトで測るべきこと」を分けて書く。原典に当たって確認できなかった点は末尾の「未確認事項」に明記する。

## 1. UBFM / Descent と、その学習フレームワーク Athénan

本プログラムの探索（UBFM/Descent）と学習方式（方策なし・価値のみ・探索値を教師にする）は、Quentin Cohen-Solal と Tristan Cazenave の一連の研究（Athénan フレームワーク）とほぼ同じ設計である。ここが最も直接的な先行研究になる。

### 1.1 Best-first minimax search（UBFM の原典）

- **タイトル**: Best-first minimax search
- **著者**: Richard E. Korf, David Maxwell Chickering
- **年/venue**: Artificial Intelligence 84(1-2):299–337, 1996
- **要点**:
  - UBFM（Unbounded Best-First Minimax）の原典。部分ゲーム木のミニマックス値と一致する葉を反復的に展開し、深さ制限なしに非一様に木を伸ばす anytime 探索。
  - Cohen-Solal はこのアルゴリズムを（当初は先行研究を知らずに）独立に再発見し、強化学習と組み合わせた。
- **本プロジェクトで測るべきこと**: 特になし（基礎文献）。

### 1.2 Learning to Play Two-Player Perfect-Information Games without Knowledge（Athénan の基礎論文）

- **タイトル**: Learning to Play Two-Player Perfect-Information Games without Knowledge
- **著者**: Quentin Cohen-Solal
- **年/venue**: arXiv:2008.01188（2020）。拡張版が Journal of Artificial Intelligence 誌および JMLR 27 (2026) 1–64 に掲載（JMLR 版は提出 2025/9、刊行 2026/4 と検索結果に表示。版ごとの対応は未確認）
- **関連する知見**:
  1. **Tree learning（tree bootstrapping）**: 学習対象を「対局で実際に通った局面」だけでなく「探索で構築した部分木の全状態」に広げる一般化を提案。後述の Minimax Strikes Back では、これが学習データ量を桁違いに増やす主因になったとされる。
  2. **Descent**: UBFM を改変し、最良の着手順列を終局まで伸ばすことで終局情報を浅い局面へ速く伝播させる探索。学習時はこちらを使い、対戦時には UBFM with Safe decision（UBFM_s、最良値ではなく最も探索された手を選ぶ変種）を使う——「学習に最適な探索と、勝つために最適な探索は別の問い」という区別が明示されている。
  3. **Reinforcement heuristic**: 対局結果の ±1 をそのまま教師にせず、「速く勝つ・遅く負ける」を優遇する depth heuristic や scoring など、より表現力のある終局評価に置き換える手法。Athénan の成績の大きな部分をこれが担う（§1.3 参照）。
  4. **Remark（JMLR 版の検索結果より）**: 「Descent が行うミニマックス値の学習は、AlphaZero や ExIt が行う終局値の学習より情報量が多い（ただし状態評価の質が良いという仮定のもとで）」。——探索値を教師にすることの利点は「葉評価の質」に条件付けられている点が、本プロジェクトの自己蒸留の限界を考える上で重要。
- **本プロジェクトで測るべきこと**:
  - 学習データに「対局で通った局面」だけでなく「探索木内の局面（s が計算された全ノード）」が含まれているか。含まれていないなら、Athénan の言う tree learning は未実施であり、同じ対局数から得られる教師データ量を増やす余地がある（対局数増・PO 増のどちらとも独立なレバー）。
  - 対局結果 `r` の教師に「勝敗だけでなく手数（速い勝ち・遅い負け）」の情報を混ぜる depth heuristic 型の変形が、LAMBDA 混合の代替・補完にならないか。
  - 学習時の探索（Descent）と対戦時の探索（UBFM_s 相当）の使い分けが現行実装でどうなっているか（最良値の手を選んでいるか、最も探索された手を選んでいるか）。

### 1.3 Minimax Strikes Back（arXiv:2012.10700）

- **タイトル**: Minimax Strikes Back
- **著者**: Quentin Cohen-Solal, Tristan Cazenave
- **年/venue**: arXiv:2012.10700（2020年12月初出、2025年5月に v2 改訂）。AAMAS 2023, pp. 1923–1931
- **概要**: 方策を使わない Athénan（Descent 探索＋価値のみ学習）を、AlphaZero の再実装 Polygames と8つのゲームで比較した論文。本プログラムと最も設計が近い対照実験。
- **関連する知見**:
  1. **教師は「部分木のミニマックス値」**: Athénan の価値教師は対局結果ではなく、探索で得た部分木のミニマックス値。これは本プログラムの `s`（探索スコア）に相当する。論文はこの教師が「過去の対局で得た知識を直接含むため、より情報量が多い」と主張する。
  2. **データ量の差**: tree learning により、同じ学習時間で Polygames の約 **296 倍**（ゲームにより 50〜700 倍）の学習状態を生成。一方で NN 評価回数は約 12.7 分の 1、状態評価回数は約 2.5 分の 1。つまり「1局あたりの情報密度」が効率の源泉。
  3. **学習速度**: 同一リソース（15日間）で Athénan は Polygames の到達性能に約 **7 倍** 速く到達（reinforcement heuristic なし）、heuristic ありでは **30 倍超**。TCGA 2020 優勝ネット（7日・100 GPU で学習）に対し、1 GPU・5日の Athénan が3ゲーム全てで勝利したと報告。
  4. **探索アルゴリズムの選択**: Cohen-Solal (2020) の実験では、tree learning と組み合わせた場合に Descent > UBFM > αβ / MCTS の順で、Descent + tree learning は MCTS + tree learning に対して全9ゲームで勝率 **+40% 以上**。また tree learning は terminal learning（対局結果のみを教師にする方式）に対してほぼ全ゲームで勝率 +40% 以上。
- **本プロジェクトで測るべきこと**:
  - 現行の教師生成が「1探索あたり何局面分の教師を生んでいるか」を数える（Athénan の効率論はこの比率が支配的だった）。対局数を増やす前に、既存の探索結果から回収できていない教師（探索木内の非対局局面）がどれだけあるかを測るのが先。
  - `s` の質を po_num の関数として測る場合、比較対象は「対局結果のみの教師で学習したモデル」との勝率差ではなく、まず `s` 自体のオラクル一致率（カテゴリ維持率など既存の audit 指標）を po_num 別に測るのが論文の構図に沿う。

### 1.4 Completeness of Unbounded Best-First Game Algorithms

- **タイトル**: Completeness of Unbounded Best-First Game Algorithms
- **著者**: Quentin Cohen-Solal
- **年/venue**: arXiv:2109.09468（2021）
- **関連する知見**:
  1. 基本形の UBFM と Descent は、強化学習の文脈では**完全ではない**：無限の計算時間を与えても完全ゲーム木の平衡点（各プレイヤーの勝利戦略）を計算できない場合がある。
  2. **Completion** という機構を加えた版（UBFM with completion / Descent with completion）は完全であることが証明された。後続の "Completeness of Unbounded Best-First Minimax and Descent Minimax"（2026、arXiv プレプリント）では completion の実効性が実験でも示されている。
- **本プロジェクトで測るべきこと**:
  - どうぶつしょうぎは完全解析済みなので、「探索が十分な予算で真の勝敗に収束するか」をオラクルで直接検証できる。現行 UBFM/Descent 実装が completion 相当の処理を持たない場合、po_num を増やしても特定の局面で値が真値に収束しない可能性が残る。**po_num を大きくしたときに `s` のオラクル一致率が単調に上がるか**を測れば、この理論的問題が実務上効いているかを判定できる（上がらない局面の特徴を調べる）。

### 1.5 On some improvements to Unbounded Minimax

- **タイトル**: On some improvements to Unbounded Minimax
- **著者**: Quentin Cohen-Solal, Tristan Cazenave
- **年/venue**: arXiv プレプリント（2025年5月提出、arXiv:2505.04525 と検索結果に表示）
- **関連する知見**（検索結果の要約に基づく。詳細は未確認事項参照）:
  1. 置換表（transposition table）による木の DAG 化、backpropagation を root まで行う Cohen-Solal 変種 vs 値が安定した時点で止める Korf & Chickering 原典、completion などの4つの改変を22ゲームで初評価。
  2. **終局評価に学習済みヒューリスティクスを使う改変は、正確な終局評価が安い設定では性能を下げた**。どうぶつしょうぎは終局判定・勝敗が正確かつ安価なので、この条件に当てはまる。
- **本プロジェクトで測るべきこと**:
  - 現行実装の backpropagation 方式（root まで伝播するか、安定したら止めるか）と置換表の有無を確認する。 Athénan 系の改良点が未採用なら、po_num を増やす前に同じ予算での探索の質が上がる可能性がある。

## 2. Expert Iteration と探索予算のスケーリング

### 2.1 Thinking Fast and Slow with Deep Learning and Tree Search（ExIt 原典）

- **タイトル**: Thinking Fast and Slow with Deep Learning and Tree Search
- **著者**: Thomas Anthony, Zheng Tian, David Barber
- **年/venue**: NeurIPS 2017（arXiv:1705.08439）
- **関連する知見**:
  1. Expert Iteration の枠組みそのもの：探索（expert）が NN（apprentice）より強いターゲットを生成し、NN がそれを一般化し、改良された NN が次の探索を強くする、というループ。本プログラムの「UBFM + 価値ネット」もこの族に属する（ただし ExIt の apprentice は主に方策で、本プログラムは価値のみ）。
  2. ターゲットの形式として、探索が選んだ1手だけを真似る chosen-action targets (CAT) より、木の方策全体を使う tree-policy targets (TPT) の方が cost-sensitive で良い、という比較がある。価値のみの場合の対応物は「root の値だけを学ぶか、木全体の値を学ぶか」であり、Athénan の tree learning は後者を採って大きく効いた（§1.3）。
  3. Cohen-Solal の Athénan 論文（§1.2）は ExIt を「知識なし自己対局学習の state-of-the-art」として直接比較対象に据え、Athénan がそれを上回ると主張している。つまり「MCTS + 方策」の ExIt 系と「Descent + 価値のみ」の Athénan 系は、同じ土俵で比較された実績がある。
- **本プロジェクトで測るべきこと**:
  - ExIt の前提は「expert（探索）が apprentice（ネット単体）より十分に強い」こと。audit_order の結果（実着手 C ≈ モデル argmax A、探索がカテゴリ維持率をほぼ押し上げていない）は、この前提が po_num=100 では弱い可能性を示す。**po_num を上げたときに C − A の差が開くか**が、予算増の効果を測る最も直接的な指標になる。
- **未確認**: ExIt 原典の中で探索予算（シミュレーション数）を系統的に振った実験の数値は、今回の調査では原典から確認できなかった（§4 参照）。

### 2.2 探索予算に関する実証的知見（KataGo の FixedN アブレーションほか）

探索予算を「固定値で振る」実験として最も明確なのは KataGo 論文の FixedN アブレーション（§3.1 に詳述）。要点をここにも引く:

- 固定 cap N ∈ {100, 150, 200, 250, 600} の全てが、ランダム化した混合予算に負けた。
- N=600 では「データ不足による過学習」で、学習ウィンドウを2倍にしてようやく緩和された。つまり**予算を上げることは、単位計算あたりの対局数（＝結果教師の数）を減らすことと等価**で、価値学習はそちらに敏感。
- KataGo 論文が引用する Forsten (2019) の Leela Zero での非公式調査では、方策学習に適した playout 数は価値学習に適した数よりはるかに大きい、とされる。

本プログラムへの含意: po_num を一律に上げる案は、KataGo の FixedN=600 の失敗モード（教師データ総量の減少＋過学習）と同じ構造を持つ。逆に「一部の手だけ深く読む」混合予算は、総計算量をほぼ保ったまま深い教師を混ぜられる。

## 3. KataGo の知見（方策ヘッドなしでも使えるもの）

### 3.1 Accelerating Self-Play Learning in Go

- **タイトル**: Accelerating Self-Play Learning in Go
- **著者**: David J. Wu
- **年/venue**: arXiv:1902.10565（2019）
- **関連する知見**:
  1. **Playout cap randomization（最重要）**: 価値目標と方策目標の間の緊張——「対局結果という価値教師は1局に1つしかなくノイズが大きい。計算量固定なら、価値学習のためには1手あたりの playout を減らして対局数を増やす方がよい。一方で方策学習には大きな playout が必要」——を解消するため、手番ごとに予算をランダム化する。具体値: 確率 p=0.25 の手番だけ full search（cap N=600、後に 1000 へ anneal）、残りは fast search（cap n=100、後に 200）。**学習データに記録するのは full search の手番のみ**。fast search では Dirichlet ノイズ等の探索的設定を切って強さを最大化する。アブレーションでの学習効率係数は **1.37 倍**（除去すると Elo 1329→1242 相当、到達時間 1.37 倍）。
     - 本プログラムへの対応: po_num=100 は KataGo の fast cap と同じ水準。現行の「全手 po=100 固定」は、KataGo の分類では FixedN=100 に相当し、アブレーションで混合予算に負けた条件そのもの。
  2. **補助ターゲット（ownership / score）**: 対局結果という「粗くてノイズの大きい二値」を、その構成要素（最終スコア差、各地点の所有権）に分解して予測させる補助損失を加えると学習効率が **1.65 倍**（今回の全手法中最大級）。著者の一般化: 「目標の部分要素を予測させることは広く効くメタ・ヒューリスティクス」。
     - どうぶつしょうぎでの対応物: 価値スカラーの補助として、例えば「最終局面での各マスの駒の所有」「勝敗が決まるまでの手数」「トライ成否」など、結果を分解した量の予測が候補になる（未検証の当てはめであり、論文の主張ではない）。
  3. **補助方策ターゲット**: 次の手番の相手の方策を予測させる補助損失（重み 0.15）で 1.30 倍。これは方策ヘッド前提なので、本プログラムには直接は使えない（「未来の量を予測させる補助タスク」という発想のみ転用可能）。
  4. **Global pooling**: 1.60 倍。アーキテクチャ側の話で本調査の主題（予算）とは別だが、係数の大きさでは playout cap randomization を上回る。
  5. 全手法の係数の積は約 9.1 倍、ELF OpenGo 比で全体約 50 倍の学習効率（19日・約27 V100 GPU で ELF の最終強さに到達）。
- **本プロジェクトで測るべきこと**:
  - **po の混合予算**: 全手 po=100 固定 vs 「25% の手だけ po=400〜1000、残り po=100（またはそれ以下）、学習記録は深く読んだ手のみ」という KataGo 型の配分を、総計算量を揃えて比較する。これが「対局数増 vs PO 増」の二択に対する文献上の第三の答え。
  - 深く読んだ手だけを学習対象にすると、1局あたりの学習局面数が減る代わりに教師の質が上がる。現行の「全手 po=100・全手学習」とどちらが audit 指標（win 維持率・draw 維持率）を伸ばすかを測る。
  - 補助ターゲット: 価値のみネットでも、結果の部分要素（例: ゲーム長、最終所有）を補助出力にする実験は、方策ヘッドなしで KataGo の最大係数（1.65 倍）の仕組みを試せる。

### 3.2 KataGoMethods.md（Wu の方法ドキュメント、GitHub）

- **タイトル**: KataGo/docs/KataGoMethods.md（"Other Methods Implemented in KataGo"）
- **著者**: David J. Wu（KataGo プロジェクト）
- **年/venue**: GitHub 上の技術ドキュメント（随時更新）
- **関連する知見**:
  1. **Short-term value and score targets**: 価値の主ヘッド（最終結果、λ→1 に対応）とは別に、**将来の MCTS 値の指数平均** `(1−λ) Σ MCTS_value(t') λ^(t'−t)` を予測する補助ヘッドを複数（19x19 で平均ホライズン約 6 手・16 手・50 手の3種）持つ。「これらの補助ヘッドは最終結果予測に対して分散の低いフィードバックを与え、主ヘッドの価値・スコア損失をわずかに改善する（古典的なバイアス・分散トレードオフ）」とされる。2022年後半の部分的な再テストの図も掲載されているが、著者自身が「厳密な検証ではない」と注意している。
     - 重要: KataGo の**主**価値ターゲットはあくまで対局結果であり、探索値は「短ホライズンの補助ターゲット」として足される。本プログラムの LAMBDA=0.5（主ターゲット自体を s と r の中点にする）とは設計が異なる。文献上の代替案は「主 = r、補助 = s（短ホライズン）」という非対称な構成。
  2. **Uncertainty-weighted MCTS playouts**: NN に「自分の短期予測が数手後の探索値とどれだけずれるか（不確実性）」を予測させ、探索の playout を不確実性で重み付けする（v1.9.0 で dynamic cPUCT と合わせて約 +75 Elo と報告）。探索予算の「配分」を値の信頼度で変える発想。
  3. **Policy surprise weighting** など方策前提の手法も多いが、価値のみの本プログラムには転用しにくい。
- **本プログラムで測るべきこと**:
  - LAMBDA 混合の代替として、「主ターゲット = r（対局結果）、補助ターゲット = s（探索値、短ホライズン）」の非対称構成を試す価値があるか。現行の 0.5/0.5 混合では、実験4.5 の結論4の通り「lose では正確な側が r なのに平均化でモデルが両教師以下に落ちる」現象が起きている。主・補助に分ければ、主ターゲットが中点に引っ張られる問題を避けつつ s の情報も使える、というのが KataGo 方式の読み替え。
  - KataGo の自己対局データ形式（katagoarchive の README で確認）: 価値ターゲットとして「カテゴリカルな対局結果」と「2つの λ による MCTS 値の TD 的ターゲット」が併記されており、本番 KataGo の学習データでも探索値系ターゲットが実際に併用されていることが分かる。

## 4. 未確認事項（原典で確認できなかった点）

- **ExIt 原典における探索予算の系統的アブレーション**: Anthony et al. (2017) の中でシミュレーション数を振って apprentice の質を測った数値は、今回の調査範囲では確認できなかった。「予算を上げると教師がどれだけ良くなるか」の直接の数値は、確認できた範囲では KataGo の FixedN アブレーションが最も具体的。

## 5. まとめ: 「対局数 vs PO 数」への文献上の答え

1. **どちらか一方を一律に上げるのは、文献上はどちらも弱い**。対局数（結果教師の数）は Exp 4 で既に飽和が見え、PO 一律増は KataGo の FixedN=600 と同じ「データ総量の減少＋過学習」の失敗モードを持つ。
2. **KataGo の答えは混合予算**: 大半の手は安い探索（po=100 級）で対局数を稼ぎ、25% の手だけ深く読み（po=600〜1000 級）、学習記録は深く読んだ手に限る。学習効率 1.37 倍のアブレーション裏付けがある。本プログラムの現行設定（全手 po=100 固定）は、KataGo の対照条件（FixedN）にちょうど一致する。
3. **Athénan の答えは情報密度**: 効率の主因は対局数でも予算でもなく、tree learning による「1探索あたりの教師数」（296 倍）と、ミニマックス値そのものを教師にすること、そして reinforcement heuristic による結果教師の表現力向上だった。PO を上げる前に、現行パイプラインが探索木内の教師を取りこぼしていないかを確認するのが先。
4. **自己蒸留の条件**: 探索値を教師にする利点は「葉評価の質が良いこと」が前提（Athénan 論文の Remark）。po_num を上げても葉は同じネットなので、上がるのは「読みの深さによる戦術的解決」の分だけ。どうぶつしょうぎは平均20手強と短く終局到達率が高いはずなので、**po_num 別の `s` のオラクル一致率と、C − A（探索がネット単体を上回る度合い）を測れば、深い読みが実際に効いているかを分離できる**。これが次にやるべき最小の検証。
5. **教師の混ぜ方の代替案**: KataGo は主ターゲット＝対局結果を保ち、探索値は短ホライズンの補助ターゲットとして足す。本プログラムの 0.5/0.5 対称混合（主ターゲットが中点になる）とは異なる設計で、実験4.5 で観測された「平均化で両教師以下に落ちる」問題への文献上の処方箋にあたる。
